# 「健康进社区」乌海市妇幼保健院进社区关爱妇女健康公益活动

> 更新时间：2026-09-17 (UTC+8)

为进一步提高社区妇女的健康水平，增强妇女自我保健意识，乌海市妇幼保健院携手镇北社区、中河源社区，开展“两癌筛查 关爱妇女”公益义诊活动。
**活动内容**
1、免费体检

项目：女科B超、妇科检查、阴道分泌物镜检、宫颈防癌细胞学检查（TCT）、乳腺检查。

2、免费健康知识讲座

内容：妇女常见病预防保健。
**活动安排**
活动时间：

2017年7月3日—2017年7月4日（镇北社区）

2017年7月5日—2017年7月7日（中河源社区）

活动地点：镇北社区服务中心
**温馨提示**
1、体检前须知：

①经腹部的盆腔B超需充盈膀胱（憋尿），请先做B超再做妇科检查。

②子宫附件B超，检查前需饮水3－5杯。

③妇科检查、宫颈防癌细胞学检查（TCT）前72小时内请禁止性生活及阴道内冲洗上药，以免影响检查结果的准确性。

2、体检中须知：

①女性体检注意事项：

a.月经期不做妇科检查；

b .无性生活女性不做除B超以外的妇科检查；

c .妇科检查前需排空膀胱。

②行B超检查憋尿，月经期不做妇检，如为异常阴道流血，请向医师说明。
