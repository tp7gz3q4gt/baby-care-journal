# 背上针灸针，踏上古丝绸之路……国家中医医疗队去甘肃干了些啥？

> 更新时间：2026-09-17 (UTC+8)

夏日的甘肃省甘南藏族自治州，天高云阔，彩色的经幡和夏花点缀在逶迤连绵的山脉和广袤的草原上，明朗而绚烂。这里是古丝绸之路河南道的重要组成部分，汉藏文化在这里交融。一路向北，相邻的是古丝绸之路南道重镇临夏回族自治州，回藏汉风情在这里碰撞。历史给居住在古丝路的百姓留下了多彩的文化，如今，国家中医医疗队给这里的百姓送来了健康。在国家中医药管理局组织下，由福建省中医药管理局牵头，委托厦门市卫生健康委会同天津市卫生健康委共同组建的国家中医医疗队赴甘肃巡回医疗队翻山越河，深入甘南和临夏巡诊。30天的时间里，12名医疗队队员为基层群众诊疗开方，为基层医务人员传授知识技术，为基层医疗机构建设建言献策，在古丝路上以中医药为基石筑起守护千家万户健康的城墙。
**01**

**送健康，走村入户疗顽疾**
“身体向左转，左手由掌变拳，上提至腰间。不用着急，慢慢来。” 甘南夏河县桑科镇贫困户道吉扎西家砖房前的空地上，医疗队领队、厦门市中医院副院长陈联发正在教授他古本易筋经十二势导引法中的动作。

陈联发（右一）教道吉扎西古本易筋经十二势导引法
原本身材壮硕的道吉扎西是家里的顶梁柱，但因为肾病治疗不及时恶化为肾癌，常年饱受腰背酸痛的困扰，身体也比以前虚弱了很多，本就贫困的生活雪上加霜。这个淳朴的藏族大汉没有想到，来自大城市的中医专家亲自上门为自己免费诊疗。为道吉扎西辨证后，陈联发教他习练可以疏通足太阳膀胱经筋的“九鬼拔马刀势”、调节足少阴肾经筋的“打躬势”、疏导足少阳经筋的青龙探爪势和调理足太阴脾经筋的“收势”，并把动作录制下来，嘱咐当地乡镇签约家庭医生学会动作，时常回访，协助患者练习，改善患者生活质量。“哎呀，真是太谢谢医疗队了。”跟着陈联发做完一遍动作后，道吉扎西一直紧皱的眉头舒展开了，他握着陈联发的手连声感谢。

医疗队到桑科镇巡诊

位于草原深处的桑科镇平均海拔3000米以上，空气稀薄、气候寒冷且昼夜温差大，当地百姓饮食多为高热量、高脂肪的牛羊肉，因而高血压、肺心病、风湿病、糖尿病、痛风、胆囊炎等疾病较为高发。但由于当地医疗资源匮乏、就医路途遥远，百姓健康意识相对薄弱，很多百姓患病后能拖就拖，就医时病情都已较为严重。有病能拖就拖，是甘南州和临夏州基层百姓就医的常态。为了转变当地基层百姓的健康观念，改善百姓的健康状况，医疗队背着诊疗工具和药品，到基层卫生院义诊、送医下乡入户。虽然颠簸的路途和高强度的工作使医疗队队员面容疲惫，但为百姓诊疗的耐心和细心丝毫没有减少。福建省泉州市中医院针灸科黄志强主任装着针灸针和小针刀，为患有骨关节病等疾病的患者诊疗；天津中医药大学第一附属医院心血管科李彬主任带着掌上超声，方便为患者进行心脏超声检查……洮砚镇、桑科镇、三甲集镇……从南到北、由东向西，30天的时间，医疗队的足印踏过甘南和临夏的9个乡镇，接诊600余名患者百姓，为多户贫困户入户诊疗，将中医药健康关怀送到百姓的心坎儿上。“中医药疗法简便验廉，看到百姓接受诊疗后病痛得以缓解，我们也很开心。”在医疗队队员们心中，百姓淳朴的笑容比草原上盛开的夏花还要绚烂。
**02**

**传技术，引得一渠活水来**
“一年之计，莫如树谷；十年之计，莫如树木；终身之计，莫如树人。”医疗队深知，下乡入户巡诊是一场及时雨，虽解了当地百姓看病就医的燃眉之急，但要保证百姓今后的持续治疗，一定要把技术留给当地医务人员。与医疗队想法契合的是，基层医务人员也对医疗队专家带来中医诊疗技术求知若渴。

医疗队开展中医适宜技术培训

探直身体，甚至踮着脚尖，目不转睛地观察黄志强娴熟地操作一根银针，在一针疗法、平衡针疗法培训中，基层医务人员不放过任何一个细节。“升提穴要采用滞针手法，待针体达到一定深度时，像这样顺时针捻转6圈，然后再按逆时针捻转6~10圈后即可将针退出。”黄志强为围在一旁的医务人员仔细讲解并演示平衡针的操作手法，医务人员一边用手机录像，一边时不时地模仿他的手法。培训实操阶段，黄志强手把手指导医务人员，待手法熟练后要求与搭档交替操作训练，培训后所教内容现场考核通过率100%。黄志强表示，平衡针操作简便、疗效好，很受当地基层医务人员欢迎。古本易筋经十二势导引法等健身功法也是当地医务人员眼中的“香饽饽”。在甘南州和临夏州，陈联发为当地医务人员进行了6场古本易筋经十二势导引法集体培训，医务人员认真学习、刻苦练习的劲头令人动容。除开展了平衡针疗法、小针刀疗法等10场中医适宜技术培训及中医导引疗法培训外，医疗队还在甘南和临夏采用多学科会诊方式对130余名住院患者进行教学查房，在基层中医院带徒义诊。此外，医疗队举办了8场学术讲座，内容涉及心脑血管、神经、内分泌、呼吸、消化、传染性肝病、风湿免疫、骨关节等疾病的诊疗和康复，几乎每场讲座都座无虚席，参加讲座的医务人员除认真听讲、做笔记外，还不时与专家进行互动，并在课后针对当地常见病与专家们展开讨论。其实在出发前，医疗队便与巡诊当地卫生健康委和相关医院领导进行充分沟通，了解当地医务人员的需求，准备相应的课程；到达当地后，医疗队根据义诊和教学查房细化调整适宜技术讲座内容，每场培训和讲座都契合当地医务人员的需求。

医疗队入户送医“医疗队给我们讲授的内容都是我们最需要的。”基层医务人员的积极反馈是对医疗队队员努力的肯定。通过跟诊、技术培训和讲座，甘南和临夏的基层医务人员中医药文化自信增强了，诊疗思路开拓了，诊疗技术提升了，很多医生希望能到医疗队专家所在医院继续进修学习。医疗队在医疗资源匮乏的地区引出一渠“活水”。
**03**

**固成效，传承创新是关键**
如何巩固巡诊成效，从根源上解决当地群众看病就医的问题，是医疗队巡诊过程中一直在思考也一直在做的事。“国家和当地政府的扶持力度还是很大的。”陈联发说，甘南州桑科镇上一排排整齐的砖房就是政府出资建设的，当地藏医药传承的也较为完整；临夏州离省会兰州近，现在医疗资源也相对充足，硬件设施也较完善。但甘南州地广人稀，医疗、人才资源相对不足，老百姓就医路途遥远；临夏州中医科室相对薄弱、缺乏高素质中医药人才、传承创新力度弱。发现了问题就要解决问题。医疗队在甘南州共举办3场促进中（藏）医药事业及中（藏）医院发展座谈会，在临夏州各中医医院结合医院和地区实际开展座谈会。抓住传承创新发展这一关键，对当地医院发展定位、学科建设、团队人才培养、新技术、新项目的开展、中医适宜技术的开展、医疗安全核心制度的落实、医院内控机制的完善等方面建言献策。医疗队建议，甘南州要积极发展中医药，推广中医适宜技术和中医导引疗法；加强中医药文化的宣传，充分利用当地丰富的天然药物资源，加强中医药传承与创新应用；加强乡镇卫生院和村卫生所的基础设施的投入，完善基本药物品种，完善与上级医院的联动及远程会诊。临夏州应加强学科建设，加强多层次培养人才，培育优势病种，规范诊疗常规，开展新技术，强化中医适宜技术培训，优化流程体验；由州医院带动县级医院，县级医院带动卫生院、卫生所，实现多级联动。同时，两州各级中医院应坚持中西医并重传承发展中医药事业，充分发挥中医药在急危重症治疗当中的协同作用，“治未病”（疾病预防）当中的主导作用，在疾病康复当中的核心作用。政府部门、卫生健康委及医院应进一步完善人才培养和激励机制，以“走出去（进修），引进来（团队柔性引进）”的形式优化团队建设。“两州不仅要培养人才，还要留得住人才，才能为百姓提供更优质的医疗服务。”陈联发说。诊疗、培训、献策，30个日夜的忙碌告一段落，医疗队踏上归途。他们在古丝路上留下了脚印，流下了汗水，留下了守护百姓健康的坚实城墙。
