# 【健康提醒】防肺癌，千万别忘了查这三项！最好提前至40岁！

> 更新时间：2026-09-16 (UTC+8)

**肺癌跟“三霾五气”有关**

专家将肺癌发病原因归结为“三霾”、“五气”：

**三霾：**

雾霾

室内的烟霾

心理的阴霾

**五气：**

烟草烟气污染

室外大气污染

厨房油烟污染

房屋装修装饰材料带来的室内空气污染

长期爱生闷气。

专家尤其强调，对很多疾病来说，心理污染最为严重，外因通过内因起作用，除了遗传方式，很多疾病的高发都和心理污染、癌症性格有很大关系。建议大家平时要及时化解不良情绪，尽可能地减少心理污染。

**雾霾天，做好六件事保护肺**
现在雾霾天很严重，也备受关注，很多人担心雾霾天是不是也会对肺造成损害呢？其实，我们在日常生活中做好自己的六件事，保护我们的肺：

1. 留意空气指数。不仅在雾霾天，要时刻注意室内外空气质量，不是天空的蔚蓝程度和室内的光亮程度觉得空气质量，如今设置软件很方便，要利用好；

2. 重点人群重点防护。孕妇、儿童、80岁以上老年人，需要重点关注；已有肺部疾病的人群，在室外空气不好的时候，尽可能减少外出和室外停留时间；

3. 回家重外衣处理。在室外空气不好的时候，外出回家要将衣服和外露皮肤需及时清洗，避免再次污染，这跟二手烟、三手烟的防护道理类似；

4. 勇敢对烟说NO！无论是家人还是朋友，或者是陌生人，都要勇敢地跟室内吸烟说不；

5. 重视口上功夫。家庭烹饪应减少烧烤、煎炸等方式，尽可能饮食清淡一些，减少室内烟霾；

6. 远离心霾。多交朋友，保持心情愉快，能做到及时排解，避免产生心理抑郁。
