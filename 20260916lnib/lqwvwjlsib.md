# 「科普」从尿痛到39.7℃高烧：一位女子忽视的尿路感染，如何演变成肾脏的“猛烈攻击”

> 更新时间：2026-09-16 (UTC+8)

近期，漯河市中心医院肾病科收治一位“急性肾盂肾炎”患者杜女士，1月余前无明显诱因出现尿烧灼感、尿痛，尿频，伴腰酸，就诊于社区医院，给予“头孢”应用1周后好转，半月前再次出现上述症状，未用药，1天前出现发热，最高体温39.7℃，尿烧灼感、尿痛，尿频，伴腰酸，尿烧灼感明显，自服“美林、泰诺”等药物对症治疗，查尿常规示:蛋白+，酮体+，白细胞 11671.4/uL，C反应蛋白 44.70mg/L，医生诊断：“急性肾盂肾炎”。那么什么是“急性肾盂肾炎”呢？如何治疗和预防呢？

肾脏是人体的“净化工厂”，而急性肾盂肾炎就是肾脏遭遇的“急性感染危机”。它不仅会带来剧烈不适，若处理不当还可能损伤肾功能。今天就来认识这种需要警惕的疾病。

**什么是急性肾盂肾炎？**
急性肾盂肾炎是肾脏肾盂部位的急性细菌性感染，属于上尿路感染的一种。简单说，就是细菌突破防线（如尿道、膀胱），逆行入侵肾脏，引发肾盂和肾实质的急性炎症。

大肠杆菌仍是最主要的致病菌（占70%~80%），其他如变形杆菌、葡萄球菌等也可能致病。细菌通常从尿道逆行而上，也可能通过血液传播（少见）到达肾脏。

**哪些人容易被“盯上”？**
女性：尤其是育龄期女性，尿道短、距离肛门近的生理特点，让细菌更易逆行；性生活、妊娠也可能增加感染风险。

尿路梗阻者：肾结石、输尿管狭窄、前列腺增生等问题会导致尿液潴留，细菌易滋生并上行至肾脏。

免疫力低下人群：如糖尿病患者、长期服用激素者、老年人，抵抗力弱时更易感染。

有基础泌尿道问题者：如反复尿道炎、膀胱炎患者，感染可能蔓延至肾脏。

**身体会发出哪些“警报信号”**
急性肾盂肾炎的症状往往“来势汹汹”，既有局部不适，也有全身反应：

全身症状：突然高热（体温可达39℃以上）、寒战，常伴头痛、乏力、食欲下降，甚至恶心呕吐。

局部症状：单侧或双侧腰痛（多为钝痛或酸痛，叩击腰部时疼痛明显）；同时可能伴有尿频、尿急、尿痛等下尿路刺激症状（提示感染可能同时累及膀胱或尿道）。

尿液异常：尿液可能浑浊、有异味，少数人会出现血尿。

一旦出现高热+腰痛，需立即就医，这可能是肾脏发出的“紧急信号”。

**如何治疗和预防？**
**治疗：及时干预，避免拖延**

抗感染是核心：需遵医嘱使用敏感抗生素，疗程通常为10~14天（比普通尿道炎更长），即使症状缓解也不能擅自停药，否则可能复发或转为慢性。

对症支持：高热时可物理降温或用退烧药；多喝水（每天1500~2000毫升）帮助冲洗尿路，同时注意休息。

若治疗不及时，可能引发肾脓肿、败血症，甚至转为慢性肾盂肾炎，长期损伤肾功能。

**预防：减少肾脏“受袭”风险**

1.  管好下尿路：积极治疗尿道炎、膀胱炎，避免感染上行。

2. 别憋尿：及时排尿能减少细菌在尿路停留的机会。

3. 注意卫生：女性尤其要注意外阴清洁，排便后从尿道向肛门方向擦拭；性生活后及时排尿、清洗。

4. 处理基础病：如控制糖尿病、治疗尿路结石，解除尿路梗阻。

5. 多喝水：每天保证充足饮水，通过尿液冲洗尿道，减少细菌滋生。

急性肾盂肾炎虽来势凶猛，但只要及时就医、规范治疗，大多能痊愈。记住：肾脏的“警报”不能等，早发现、早处理，才能守护好我们的“净化工厂”。
